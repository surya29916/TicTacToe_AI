# Tic-Tac-Toe AI Game

An interactive Tic-Tac-Toe web application built using Python, Flask, HTML, CSS, and JavaScript.

## Features

- Play against an AI opponent using the Minimax algorithm.
- Two-player mode on the same device.
- Interactive 3×3 game board.
- Automatic winner and draw detection.
- Scoreboard to track game results.
- Responsive user interface.

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Minimax Algorithm

## How to Run

1. Install Python 3.
2. Install Flask:

   ```bash
   python -m pip install flask
   ```

3. Open a terminal in the project directory.
4. Run the application:

   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000` in your browser.

## Game Modes

**Play vs AI:** Play against the computer.

**Two Players:** Two people can play on the same device by taking turns.

## Project Purpose

This project demonstrates basic web development, game logic, and an AI decision-making algorithm.
